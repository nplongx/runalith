### Node same-task retry preflight differential slice (2026-11-03)

`rust/scripts/generate-node-agent-retry-oracle.mjs` calls the actual public `WorkflowStore.beginAgentRetry` in a disposable SQLite database. Its reproducible `node-agent-retry-v1.json` fixture covers 19 cases: 2 successful retry plans and 17 rejections spanning argument validation, task/job gate, retryable task state, session presence and takeover permission, session state, unsettled lease, malformed/fractional/non-numeric attempt values, multiple active attempts, attempt/run binding mismatch and safe-integer exhaustion. Successful cases also capture Node durable readback: task remains `running`, session becomes `ACTIVE`, session attempt advances, exactly one attempt remains open, and any stale prior attempt is failed. `runalith-domain::node_task_retry` matches exact Node error categories/messages, next-attempt calculation and prior-attempt identity. It receives a snapshot containing an already-resolved permission boolean; it does not authenticate that permission, take a writer lock, mutate session/task/attempt rows, settle a lease or append an event. The existing Node `test-agent-retry-atomicity.js` independently still passes injected event-write rollback, SIGKILL/independent reopen recovery, retry and duplicate guard. This slice is preflight parity only; the combined Node transaction cannot be moved into a split Control/Execution topology without a ratified cross-part retry contract and durable outbox/inbox protocol.
