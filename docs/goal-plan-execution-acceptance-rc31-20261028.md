# Goal/Idea Graph → Plan Graph → Execution Graph acceptance — RC.31

**Production decision: `BLOCKED`.** RC.31 is a versioned successor to RC.30. It retains the authenticated Goal/Idea source guard at Execution Graph creation and readback, and makes Plan Graph readback return a structured, fail-closed stale result when stored source revalidation fails. RC.30 and earlier candidate archives remain preserved; this successor does not weaken identity, evidence, reviewer, approval, or dispatch gates.

## Implementation change

`adaptive_goal_plan_proposal_get` now catches only coded `SOURCE_*` failures from `readAdaptiveGoalPlanProposal` and returns `found:false`, `status:stale`, a stable `reason`, and the source error code/message as a blocker. It does not modify the event, repair the plan, approve it, or promote its source. Unexpected errors still propagate. This covers old proposals whose saved compiled workflow plan no longer matches the current template, instead of exposing that expected stale state as an unstructured MCP error.

The end-to-end regression runs against a disposable workflow database. It deliberately mutates a test-only Plan Graph event to force `SOURCE_WORKFLOW_PLAN_HASH_MISMATCH`, asserts a structured stale response, restores the exact original event payload bytes, and confirms the original proposal readback succeeds afterward. This test is not evidence about production provenance.

## End-to-end coverage retained

The isolated producer E2E creates nine typed producer artifacts through real task completion APIs, checks result/attempt/artifact/completion-event lineage and hashes, verifies a signed Goal/Idea snapshot using isolated test keys, checks supporting evidence on every Plan Graph step, preserves the dependency DAG, persists and reads back the review-only Execution Graph proposal, verifies separate reviewer identity, pins the immutable plan, and exercises isolated dispatch. Negative cases remain fail-closed for invalid/mutated artifacts, missing completion, invalid attempts, failed producers, stale snapshots, replay/expiry, reviewer changes after approval, and legacy unverified source promotion. These results establish local integration behavior only.
