# Triage Labels

The engineering skills use five canonical triage roles. Map them to these GitHub label names:

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires human implementation or intervention. |
| `wontfix` | `wontfix` | Will not be actioned. |

Use the exact label strings above whenever a skill refers to one of the canonical roles. This file defines the mapping; it does not create or modify labels in GitHub.
