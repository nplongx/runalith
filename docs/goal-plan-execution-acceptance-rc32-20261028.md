## Acceptance scope

- Goal/Idea current-snapshot identity, typed artifact lineage and independent verifier provenance remain prerequisites to source-backed Plan Graph acceptance. Empty evidence manifests, stale or malformed producer artifacts, provenance mutation and unauthenticated source must fail closed.
- Every Plan Graph step still needs correctly typed supporting evidence whose bytes and producer/result/attempt/completion lineage revalidate. A structurally complete proposal is not eligible solely because paths, hashes or fields are present. Exact snapshot identity and immutable-plan binding must remain current through approval and dispatch.
- Execution Graph proposals remain persisted/read-back objects gated by source-backed Plan Graph identity, independent reviewer identity, authorized approval and a final pre-dispatch revalidation. Local tests do not populate production proposal records and cannot close a release gate.
- Trust verification distinguishes schema-version errors from schema errors and now has a read-only host-environment comparison for the exact versioned entrypoint. It must not print key material and cannot substitute for the active trust-ledger or independent checkpoint checks.
- Store cancellation is refused while a child task's durable execution is still running or any started attempt remains open, even when an inconsistent item status claims an earlier terminal disposition.

The remediation-plan tests prove schema v2 is accepted only with diagnostic-only metrics and no lifecycle authority. Execution batch tests prove drain-before-terminalization and preserve uncertainty where task or attempt state remains unresolved.

The existing current-scope E2E continues to exercise typed producer artifacts, artifact/result/attempt/completion lineage, verifier signatures, supporting evidence for plan steps, current-snapshot staleness, review-only Execution Graph persistence, separate reviewer identity, approval, immutable plan pinning, replay/expiry, provenance/content mutation and isolated dispatch.
