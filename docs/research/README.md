# Research artifacts

## Adaptive Goal Graph (AGG)

The AGG/Runalith internal empirical study and its reproducible figures are in
[agg-empirical-evaluation/](agg-empirical-evaluation/README.md).

The study uses project-owned synthetic benchmark artifacts to evaluate search
quality, Phase 2 discriminator metrics, the Phase 3 Beam/MCTS comparison, and
the current evidence status for Phase 4 knowledge reuse. It does not claim
production effectiveness or formal release acceptance.
